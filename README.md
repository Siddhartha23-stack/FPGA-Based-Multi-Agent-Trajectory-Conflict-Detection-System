
🚁 FPGA-Based Multi-Agent Trajectory Conflict Detection System

Excited to share our course-based project focused on improving safety and coordination in autonomous drone swarms.

As UAVs and multi-agent autonomous systems become increasingly common in applications such as surveillance, disaster response, logistics, and aerial mapping, real-time conflict detection is critical for preventing collisions and ensuring safe operation.

Our project presents a simulation-driven framework that combines Python-based drone trajectory simulation with an FPGA-inspired parallel processing architecture for low-latency conflict detection.

🔹 Key Features:
• Multi-agent drone simulation in a shared environment
• Real-time trajectory monitoring
• Conflict detection using relative position and velocity analysis
• Distance-threshold and collision-risk evaluation
• FPGA-inspired parallel processing model
• Real-time visualization of drone interactions
• Comparison of CPU-based and FPGA-based approaches

🛠 Technologies Used:
Python, Pygame, Verilog, FPGA Concepts, UAV Systems, Multi-Agent Systems, Simulation Modeling

📈 Highlights:
• Reduced detection latency through parallel processing
• Scalable architecture for large drone swarms
• Dynamic conflict visualization and monitoring
• Hardware-oriented design suitable for future FPGA deployment

This project strengthened our understanding of FPGA architectures, Verilog design, UAV coordination, parallel computing, and safety-critical system development.
